# Excel_Project_RetailMax_Sales_Data_Analytics
My project demonstrating my Excel skills.   
💡 Quick Start Notes:  
    Enable Editing: When opening the workbook, click "Enable Editing" at the top of your screen to unlock the full interactive features and custom navigation tabs.     
⚠️Caution: You will get ERROR messages at the start due to sheet protection and data model loading. DO NOT WORRY IT DOESN'T AFFECT THE WORKBOOK'S DATA. You have to manually unprotect all the sheet (no password in protection) and refresh all. But you don't have to refresh normally all the data is pre-loaded.
